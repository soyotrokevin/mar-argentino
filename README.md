# Mar Argentino

Exploración submarina interactiva en 3D desde la superficie del Atlántico Sur hasta el lecho marino abisal.

**[Jugar en línea →](https://soyotrokevin.github.io/mar-argentino/)**

## Modos de juego
- **Misión:** Catalogá las 7 especies marinas antes de que termine el tiempo límite de 2 minutos.
- **Exploración libre:** Sumergite sin límite de tiempo para recorrer la columna de agua, observar las especies y analizar sus modelos en 360° o en vista de Rayos X.

## Especies incluidas
- **Ballena Franca Austral** (*Eubalaena australis*) — Modelo 3D: DigitalLife3D (`CC-BY-NC-4.0`)
- **Medusa Abisal** (*Leptomedusae*) — Modelo 3D: n- (`CC-BY-4.0`)
- **Calamar Bioluminiscente** (*Histioteuthis bonnellii*)
- **Pez de Aguas Profundas** — Modelo 3D: Microsoft / Khronos Group (`CC0`)
- **Coral Blando** (*Alcyonacea*) — Modelo 3D: Sharon Kunne (`CC-BY-4.0`)
- **Estrella de Mar Robusta** (*Asteroidea*) — Modelo 3D: kodai100 (`CC-BY-4.0`)
- **Pepino de Mar Abisal** (*Benthodytes lingua*)

## Controles
- **Teclado:** `W` / `S` avanzar y retroceder · `A` / `D` girar · `↑` / `↓` ascender y descender (incluso podés asomar apenas sobre el oleaje de la superficie) · `L` reflectores · `E` fotografiar / registrar · `M` sonido · `Esc` ajustes
- **Móvil / Táctil:** botones direccionales y controles rápidos en pantalla.
- **Joystick USB / Bluetooth:** configurable desde **Ajustes → Joystick** con diagrama en vivo y reasignación de ejes y botones.

## Tecnologías
Renderizado 3D en tiempo real con [Three.js](https://threejs.org/) (`MIT`) y audio procedural mediante Web Audio API.
